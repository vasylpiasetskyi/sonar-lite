# Rule: Frontend

- React + TypeScript. No `any`.
- TailwindCSS for styling.
- Responsive layout by default.
- Build reusable components; don't duplicate markup across screens.
- Every data-fetching view needs explicit loading, error, and empty states.
- Aim for a consumer-product feel, not an internal admin panel.
- Don't add abstraction (context, generic wrappers) before there are at least two real use cases for it.
